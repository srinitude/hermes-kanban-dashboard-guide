Keep unrelated work on separate boards

Each board has its own cards, tenants, and assignees. Workers on one board do not see another board's tasks.

Switch boards

  1. Open the selector under Board.
  2. Pick a board. Its task count appears beside the name.
  3. Search and filter fields reset so an old filter cannot hide the new board.

If the default board is empty and it is your only board, Hermes keeps the switcher compact. New board, Settings, and Help still appear.

Create a board

  1. Click + New board.
  2. Enter a required lowercase slug. Hyphens and underscores are allowed.
  3. Add an optional display name, description, and one-character icon or emoji.
  4. Set an existing absolute project directory. Git repositories default new tasks to preserved worktrees. Other folders default to a preserved directory.
  5. Leave Switch to this board on if you want to open it now.

Change or archive a board

Settings changes the display name, description, and default project directory. A task can override that directory when you create it. Archive appears on non-default boards. It moves the whole board to boards/_archived/, removes its tasks from the UI, and keeps it recoverable.

Board archive and task delete are different. Archiving a board is recoverable from disk. Deleting a task says it cannot be undone.
