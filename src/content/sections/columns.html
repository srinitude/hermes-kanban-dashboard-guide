What every column means

ColumnPut a card here whenWhat Hermes does
TriageYou have a rough idea, not a full task.Use Specify for one refined card or Decompose for a parent plus child cards. Auto-decompose can do this for new triage cards.
TodoThe task is known but has an open parent, missing detail, or no reason to run yet.It waits. A child can move forward after every parent is done.
ScheduledThe work should wait for a later follow-up instead of a human answer.It stays out of the ready queue. This column may be filled by an agent or Kanban command; you can still drag cards in or out in the dashboard.
ReadyThe request is clear, dependencies are done, and it is safe to start.The dispatcher looks for a worker. A visible Needs assignee badge means the card will wait until a profile is assigned.
In ProgressA worker has claimed the card.Hermes tracks the claim, run, log, and events. You cannot set this state directly; only the claim path can.
BlockedA worker needs human input or the goal loop ran out of turns.The claim is released. Add a comment or fix the task, then use Unblock to return it to Ready.
ReviewA workflow has queued a review pass.A review worker can claim the card as a separate run. This is mostly workflow controlled, but it appears on the board and accepts drag and drop.
DoneThe expected result exists and has been checked.The claim is released and dependent children can become Ready. A manual completion requires a summary.
ArchivedYou want to keep a card but hide it from daily work.It stays in the database. Turn on Show archived to see it again.
Installed build note: Scheduled and Review are first-class states in the active backend. Some older docs name only six active columns. This guide includes every state the current dashboard can return.
