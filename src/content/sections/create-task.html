Create a card with the right safety settings

Click the + in the column where the task should start. The title is the only required field, but workspace and assignee decide whether the work is safe and whether it starts.

FieldHow to choose
TitleState the result, not just the topic. Press Enter to create or Shift+Enter for another line.
Assignee or specifierEnter a Hermes profile name. Leave it blank to let the dispatcher choose. In Triage, this is the profile that specifies the idea.
PriorityUse 0 for normal work. Higher numbers are claimed first.
SkillsEnter extra skill names separated by commas. Every worker already gets the built-in Kanban worker procedure.
WorkspaceTemporary is deleted on completion. Git worktree and Directory are preserved. The path is shown for preserved choices and can inherit the board project directory.
Parent taskChoose one parent when this card must wait. The child stays back until the parent is done.
Goal modeTurn it on for open-ended work that may need several agent turns. A judge checks the card after each turn. Leave max turns blank for the backend default of 20, or set a positive limit.
Before using Temporary: assume every file left there will be erased when the task finishes. Choose a worktree or directory for anything you need to keep.
