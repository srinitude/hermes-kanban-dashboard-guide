Find work and keep the view current

ControlWhat it does
SearchMatches task ID, title, description, result, latest run summary, assignee, and tenant across visible columns.
TenantShows one free-form tenant tag. The list contains tenants already present on the board.
AssigneeShows cards assigned to one Hermes profile.
Show archivedAdds archived cards to the board.
Lanes by profileGroups the In Progress column by assignee. It affects that column only.
Nudge dispatcherAsks the dispatcher to claim up to eight ready tasks now.
RefreshForces a database reread. Normal task events already refresh the board through a live connection.
Clear filtersClears search, tenant, assignee, and Show archived. It does not change Lanes by profile.
