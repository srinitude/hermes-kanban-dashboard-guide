Set how Hermes routes multi-agent work

The Orchestration panel sits above the filters. Its status says Auto or Manual. Use Reload after a profile or setting changes on disk.

Routing settings

  • Set Orchestrator profile to the profile that owns a root task after fan-out and checks whether its children finished.
  • Set Default assignee to the normal worker profile for a task that names no assignee.
  • Turn on Auto-decompose triage tasks if the dispatcher should split new rough ideas. Leave it off when you want cards to stay in Triage until you click Decompose.

Describe each profile

  • Write one sentence about the work a profile does well, then click Save.
  • ⚗ Auto can draft that sentence from the profile's skills and model.
  • Read every draft before saving it. The decomposer relies on these descriptions when it chooses workers.
This panel does not choose the decomposition model. It chooses profiles. Configure the model under auxiliary.kanban_decomposer.
