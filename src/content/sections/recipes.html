Four workflows you will reuse

Turn a rough idea into parallel work
Create in Triage→Open the card→Decompose→Check children and assignees→Move ready children to Ready→Nudge dispatcher
Answer a blocked worker
Open Blocked card→Read result, log, and comments→Add the missing answer→Unblock→Nudge dispatcher
Recover a stale In Progress card
Check age color→Read latest run and log→Use suggested diagnostic→Reclaim only if needed→Reassign and return to Ready
Separate projects safely
Create one board per project→Set its project directory→Use preserved task workspaces→Archive the board when inactive
