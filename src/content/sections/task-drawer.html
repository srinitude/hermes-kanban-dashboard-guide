Use the task drawer as the card's control room

Open a card to see the full record. Close it with Esc, the ×, or the shaded backdrop. Escape does not close it while you edit the title or description, which protects unfinished text.

Identity and routing

Edit title, assignee, priority, and the per-task model override. Read tenant, workspace kind and path, required skills, and goal-mode settings. The model list is grouped by provider and warns when a model is outside Hermes' known set.

Status actions

Move to Triage or Ready. Block, Unblock, Complete, or Archive when the current state allows it. There is no direct In Progress button because only a real worker claim may create that state.

Shape rough work

✨ Specify appears only in Triage and refines one card. ⚗ Decompose can keep one refined card or create child cards. The response tells you which happened.

Description and links

Edit the Markdown description. Add or remove parent and child cards from the Dependencies section. A parent must finish before its child can run.

Results

Read Result, the latest run summary, and child results. A parent card gathers completed child output so the orchestrator can judge the whole job.

Attachments

Upload several files. Uploads run one at a time, so a partial failure is clear. Download a saved file or delete it after the confirmation. File names and sizes appear in the list.

Conversation and history

Add comments, read recent task events, and inspect run history. Three runs show first; use Show earlier runs for more.

Worker log

Refresh the latest worker log. The viewer shows up to 100 KB and tells you if the log was truncated. Use the shown path when you need the full file.

Home notifications

If a messaging platform has a home channel, a toggle can send this task's completed, blocked, or gave_up updates there. The section stays hidden when no home channel exists.
