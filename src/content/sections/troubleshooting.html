Fix the usual problems

What you seeWhat to check
Ready card never startsAssign a profile if the card says Needs assignee. Check the gateway and dispatcher, then click Nudge dispatcher.
Card seems missingClear filters, switch to the right board, and turn on Show archived.
Move to Done stopsEnter a non-empty completion summary. Canceling or leaving it blank stops the move.
Move to Ready failsA parent may still be open. Check Dependencies and the inline error beside the action row.
Bulk change partly failsFailed cards are marked and the banner names up to three errors. Refresh, fix those cards, and retry only them.
Board looks staleClick Refresh. If the live connection says authentication failed, reload the page to get a new session token.
Kanban tab reports a rendering errorClick Reload view. If it returns, check dashboard logs.
Task was created with a warningThe card exists, but a ready task may sit idle if no gateway is running. Start or repair the gateway before retrying dispatch.
